# App Store screenshots — capture plan (Minimum Stress)

Do not fabricate screenshots or show features the app does not have. Capture the
**real** app UI from the production build (the shell loading minimumstress.app, or
the web app at a phone width) and drop in the captions below.

## Required sizes (App Store Connect, 2026)
- **6.9" (iPhone 16 Pro Max):** 1320 × 2868 px (portrait). Required set.
- **6.5" (iPhone 11 Pro Max / XS Max):** 1242 × 2688 px. Provide if the 6.9" set
  is not auto-scaled.
- 3–10 screenshots per size. 5 is plenty for v1.
- PNG or JPG, sRGB, no transparency, no rounded-corner/device frame added by you
  (Apple frames them), no pricing overlays, no fake Apple UI.

## Preferred sequence + captions
1. **Discover spaces** — the Discover list/rail with real listings and the
   optimized card thumbnails. Caption: **"Find professional space near you."**
2. **Space Detail** — a listing's gallery (detail images), price, "good for", and
   the approximate-area line. Caption: **"See the room. Book the hour."**
3. **Book by the hour** — the time/hour selection or the payment sheet step (do
   not capture real card entry). Caption: **"Pay for only the time you need."**
4. **Professional trust** — the verification/trust screen (identity, insurance,
   professional proof requirements). Caption: **"Verified professionals. Real
   accountability."**
5. **Host dashboard** — the host's listings/calendar. Caption: **"Put your empty
   hours to work."**

## How to capture (no Mac simulator required for drafts)
- Fastest, on any machine: open `https://minimumstress.app` in a Chromium browser,
  DevTools → device toolbar → set **1320 × 2868** (or a 1:2.17 ratio), sign in as a
  practitioner with seeded/real inventory, and use the browser's full-size screenshot.
  Re-scale to the exact px if needed; keep the status bar clean.
- Preferred, on a Mac: run the shell in the iOS Simulator (iPhone 16 Pro Max),
  navigate each screen, and use Simulator → File → Save Screen (exact device px).
- Keep the same signed-in demo state across all shots so they read as one flow.

## Do not
- No screenshots of a room's exact address or door code (those appear only
  post-booking; keep them out of marketing).
- No "therapy", no guaranteed-income/clients claims, no fake reviews.
