# Age rating — App Store Connect questionnaire (Minimum Stress)

The app is for adult professionals, not children. It has private booking-scoped
messaging and host-uploaded listing media, and platform rules prohibit adult/sexual
uses. Answer the 2026 questionnaire truthfully — do not claim "no communication" or
"no user content," because both exist.

## Recommended answers

| Question | Answer | Why |
|---|---|---|
| Cartoon or Fantasy Violence | None | Not present. |
| Realistic Violence | None | Not present. |
| Sexual Content or Nudity | None | Prohibited by platform rules; listings are professional rooms. |
| Profanity or Crude Humor | None | Not part of the product. |
| Alcohol, Tobacco, or Drug Use | None | Not present. |
| Mature/Suggestive Themes | None | Professional wellness/movement context only. |
| Horror/Fear | None | Not present. |
| Medical/Treatment Information | None | The app rents space; it makes no medical/treatment claims and avoids "therapy". |
| Gambling | None | Not present. |
| Contests | None | Not present. |
| **Unrestricted Web Access** | **No** | The shell loads only the app's own site; external links (Stripe, legal) open the system browser, but the app is not a general web browser. |
| **User-Generated Content** | **Yes** | Hosts upload listing photos/video; both parties exchange messages on a confirmed booking. Moderation exists: contact-detail redaction, in-thread Report and Block, and staff review of reports. |

## Result
- **Recommended rating: 17+** (or the questionnaire's equivalent once UGC is
  declared). Even though individual content descriptors are "None", declaring
  User-Generated Content typically raises the rating, and the app is intended for
  adult professionals — a higher floor is correct here, not a risk.
- **Made for Kids:** No. **Kids category:** No.
- **Age gate in app:** not separately required, but the professional-verification
  gate and terms already establish an adult, professional audience.

## Do not
- Do not answer "No" to User-Generated Content — messaging and uploaded media are
  real UGC and Apple checks for the matching safety controls (which now exist:
  Report/Block, redaction, staff review — see migration 0067 and the report).
